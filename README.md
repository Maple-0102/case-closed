# Trend Detective

A tool for the NASA Space Apps Challenge 2026 challenge **"Be An Earth System Trend Detective!"** (Singapore local event, virtual).

This repository was created on **14 November 2026 at 09:22 SGT**, after the hackathon started (09:00 SGT). All code and data in it were written or downloaded during the hackathon.

> Status: in progress.

## What it does

Pick a question, a place and an Earth-science variable. The tool shows how the variable changed year by year and answers four questions: did it change, which way, by how much, and how sure we are (Mann-Kendall test with confidence intervals).

## Use of Super Intelligence (SI) tools

We used Anthropic's Claude (an AI assistant) as a coding and data-processing assistant. Specifically:

- Writing and debugging JavaScript, HTML/CSS and Python code in this repository.
- Writing download and data-conversion scripts, and driving the browser to download data from NASA Giovanni and AppEEARS.
- Drafting documentation text, which the team reviewed and edited.

The team chose the questions, places, variables, statistical approach and design. Files written with SI help say so in a header comment, and data files record how they were produced in their metadata. No images, video or audio in this project were generated by SI.
